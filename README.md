# さくのポートフォリオ

UIUXデザイナー・デザインエンジニアを目指す、さくのポートフォリオサイトです。
「自己紹介」「作品」「連絡先」の3つのセクションで構成しています。

## 公開URL

<https://saku-murayama-portfolio.vercel.app/>

## 使用技術

- HTML
- CSS（Flexbox / Grid / メディアクエリ）
- JavaScript

フレームワークやライブラリは使わず、素の HTML / CSS / JavaScript だけで作っています。

## 工夫した点

### 赤瓦モード
ヘッダーのボタンで、白い背景の「ライトモード」と赤瓦色の「赤瓦モード」を切り替えられます。
JavaScript は `body` にクラスを付け外しするだけにして、色の指定は CSS にまとめました。

### 作品の絞り込み
「すべて」「Web」「デザイン」「その他」のボタンで、作品をカテゴリごとに絞り込めます。
各作品に `data-category` 属性でカテゴリを持たせているので、カテゴリを増やすときは HTML を書き足すだけで済みます。

### スマホ対応
メディアクエリで、画面が狭いときの文字の大きさや余白を調整しています。
作品カードは Grid の `auto-fill` で、画面の幅に合わせて列の数が自動で変わります。

## ファイル構成

```

script.js   … 赤瓦モードと作品の絞り込み
```
